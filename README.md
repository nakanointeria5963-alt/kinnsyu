# 🌱 禁酒トラッカー

禁酒の継続をサポートするシンプルなWebアプリPWAです。サーバー不要で、データはすべて端末のブラウザ（localStorage）に保存されます。

## 主な機能

- **継続日数カウンター** — 禁酒開始日からの日数を自動表示。飲酒（スリップ）を記録するとリセットされ、その日から再スタート
- **肝臓の回復イメージ** — 継続日数のとなりに肝臓のイラストを表示。30日かけて濃い茶色から健康的なピンク色へ1日ずつ変化し、「健康な肝臓まであと◯日」を表示（回復のイメージ図）
- **節約・健康の可視化** — 節約金額 / 削減カロリー / 飲まなかった杯数を自動計算
- **目標日数の設定** — 好きな目標（例: 30日）を決めて、ホーム画面で達成率・残り日数をバー表示。達成すると祝福表示
- **リマインダー通知** — 毎日決めた時刻に、その日まだ記録していなければブラウザ通知でお知らせ（要通知許可）
- **達成バッジ** — 1日・3日・1週間・30日・90日・1年など9段階のマイルストーン
- **毎日の記録** — 気分（5段階）・飲みたい気持ち（渇望0〜10）・メモを保存
- **カレンダー & 気分グラフ** — 禁酒/飲酒日をカレンダー表示、直近14日の気分推移を折れ線グラフで表示
- **AIの今日のアドバイス** — 継続日数と年齢（生年月日から算出）をもとに、その日のアドバイスを表示。医学的な情報と禁酒の豆知識を毎回含み、直近と重複しないよう工夫。「🔄」で別のアドバイスに切り替え可能（端末内で生成、外部送信なし）
- **今日のタロット占い** — 生年月日をもとに、大アルカナ22枚から今日の一枚を表示（禁酒とは無関係のお楽しみ）。カード・正逆位置・総合運の星・ラッキーカラー/ナンバー/アイテムを毎日更新
- **モチベーション** — 継続を後押しする言葉を表示
- **PWA対応** — スマホのホーム画面に追加してオフラインでも利用可能
- **ダークモード** — OSの設定に自動追従

## 使い方

1. `index.html` をブラウザで開くだけです。
2. 右上の ⚙️ から「禁酒を始めた日」「1日の平均飲酒量」「1杯の金額・カロリー」を設定します。
3. 毎日「チェックイン」または「記録」で気分を残しましょう。

### ローカルで動かす（任意）

PWA機能（オフライン・インストール）を試す場合は簡易サーバー経由で開きます。

```bash
# Python があれば
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の構造 |
| `styles.css` | デザイン（ライト/ダーク対応） |
| `app.js` | ロジック・データ保存 |
| `manifest.json` | PWA設定 |
| `sw.js` | オフライン用サービスワーカー |

## プライバシー

データは外部に送信されません。すべて利用中の端末内にのみ保存されます。
