# 🌱 禁酒トラッカー

禁酒の継続をサポートするモバイルファーストのWebアプリ（PWA）です。サーバー不要で、データはすべて端末のブラウザ（localStorage）に保存されます。

## 主な機能

### 継続の見える化
- **円形プログレスリング** — 継続日数と次のマイルストーンまでの進捗をひと目で表示
- **連続・通算・最長の3つの日数** — スリップしても通算日数と節約額は守られる設計
- **肝臓の回復イメージ** — 30日かけて濃い茶色から健康的なピンク色へ1日ずつ変化
- **通算の節約金額・削減カロリー・杯数・禁酒率** を自動計算
- **目標日数** — 達成率バー表示。達成すると紙吹雪でお祝い 🎉

### 毎日の記録
- **初回オンボーディング** — 3ステップで開始日・理由・習慣・目標を設定
- **記録シート** — 気分（5段階）・渇望（0〜10）・きっかけタグ・メモ
- **スリップ（再飲酒）の優しい記録** — 今日/昨日を選択、きっかけメモ、取り消し（undo）対応
- **カレンダー** — 日付をタップして過去の記録の閲覧・編集・スリップ修正
- **気分と渇望のグラフ**（直近14日）と**きっかけの傾向分析**

### 続けるための仕掛け
- **🆘 SOSボタン** — 飲みたい波が来たら60秒の深呼吸ガイド＋あなたの「禁酒する理由」を表示
- **達成バッジ** — 1日〜1年の9段階。達成日も記録され、達成時は紙吹雪
- **AIの今日のアドバイス** — 継続日数と年齢に合わせ、医学的情報と豆知識を毎回含む（端末内生成）
- **今日のタロット** — 生年月日から毎日1枚。タップしてめくる演出付き
- **リマインダー通知** — 毎日決めた時刻に、未記録ならお知らせ

### アプリとしての完成度
- **PWA対応** — ホーム画面に追加してオフラインでも利用可（PNGアイコン・iOS対応込み）
- **下部ナビゲーション** — 片手で届く、スマホアプリと同じ操作感（セーフエリア対応）
- **テーマ切替** — 自動（OS追従）/ ライト / ダーク
- **バックアップ** — 記録をJSONでエクスポート/インポート（機種変更・データ消失に備えて）
- **アクセシビリティ** — キーボード操作・スクリーンリーダー・視差軽減設定に配慮

## 使い方

1. `index.html` をブラウザで開くだけです（初回はオンボーディングが起動します）。
2. 毎日「今日を記録する」から気分を残しましょう。
3. 飲みたくなったら 🆘 ボタンで深呼吸を。

### ローカルで動かす

PWA機能（オフライン・インストール・通知）を使う場合は簡易サーバー経由で開きます。

```bash
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

### テスト

```bash
# サーバーを起動した状態で
python3 -m http.server 8130 &
node tests/smoke.cjs   # 全機能のE2Eスモークテスト（要 Playwright + Chromium）
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の構造（ホーム/記録/統計/達成＋各シート） |
| `styles.css` | デザインシステム（ライト/ダーク対応） |
| `app.js` | アプリ本体（状態管理・描画・機能） |
| `util.js` | 共有ユーティリティ（日付・乱数・DOM） |
| `advisor.js` | AIアドバイス生成エンジン |
| `tarot.js` | タロット占いエンジン |
| `manifest.json` / `icon-*.png` | PWA設定・アイコン |
| `sw.js` | Service Worker（HTMLはネットワーク優先で更新が確実に届く） |
| `tests/smoke.cjs` | E2Eスモークテスト |

## プライバシー

データは外部に送信されません。すべて利用中の端末内にのみ保存されます。
